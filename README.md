Christian, husband, dad. I run a manufacturing company for a day job and build tools for work, for play, and for my many, many hobbies. Linux (Omarchy) is my daily driver, I keep a homelab occupied, and all the new friends I've made in the last year are agents.

**Things worth a look**

- [**vimchi**](https://github.com/gig3m/vimchi): a browser Vim tutor that runs from hjkl up through macros, regex and the Neovim plugins people actually use.
- [**wilco**](https://github.com/gig3m/wilco): a self-hosted JMAP mail client with one indexed inbox across Fastmail accounts.
- [**applenotes**](https://github.com/gig3m/applenotes): reads and writes Apple Notes from Linux over Tailscale, with an old Mac as the bridge. REST and MCP. [**anotes**](https://github.com/gig3m/anotes) is the desktop app on top of it.
- [**drip**](https://github.com/gig3m/drip): push a screenshot or file to your server and get back an expiring URL a coding agent can fetch.
- [**covey**](https://github.com/gig3m/covey): like Laravel Herd, but for Linux. Make a directory and get a working HTTPS PHP site.
- [**nuphykit**](https://github.com/gig3m/nuphykit): a reverse-engineered protocol and tooling for the NuPhy Air100 V3 keyboard.

**For Omarchy:** [omamate](https://github.com/gig3m/omamate) (chess), [glyphfield](https://github.com/gig3m/glyphfield) (a terminal screensaver), [omarchy-power-chargehold](https://github.com/gig3m/omarchy-power-chargehold) (a battery charge cap that holds), and [omacal](https://github.com/gig3m/omacal) (Fastmail and iCloud calendars in the clock).

**For the kids:** [omarchy-elementary](https://github.com/gig3m/omarchy-elementary) and [elementary-curriculum](https://github.com/gig3m/elementary-curriculum) (a first-computer course for going from an iPad to Linux), and [arduino-missions](https://github.com/gig3m/arduino-missions) (printable Arduino lessons for kids).
