**Real work, written up**

Most of what I build for businesses is private, so these are short write-ups of what it was and what changed. All three are for the manufacturing company I run.

- [**Replacing a manufacturer's ERP, and wiring it to QuickBooks**](work/erp-and-quickbooks.md): a new system of record built with coding agents, plus an automatic QuickBooks sync that ended the month-end journal entry.
- [**Letting staff ask an AI assistant about the business, safely**](work/ai-assistant-on-business-data.md): a custom Claude connector where each person signs in as themselves, reads are read-only, every answer links back to the ERP, and changes are proposals a manager approves.
- [**A hiring site for a business that mostly hires by word of mouth**](work/hiring-site.md): email sign-in, a DOT driver application, encrypted applicant data, and an assistant that can post openings but sees masked ID numbers.

**For churches and nonprofits**

- [**sermon-cut**](https://github.com/gig3m/sermon-cut): finds the sermon in a two-hour church livestream, cuts it with an intro card and uploads it for review. Local transcription, with Claude finding the sermon and drafting the title and chapters.
- [**exodon**](https://github.com/gig3m/exodon): screens cold outreach and phishing with your own allow and block lists plus a local model, so your mail never goes to a hosted AI.

**AI and agents in practice**

- [**tack**](https://github.com/gig3m/tack): a self-hosted kanban board that agents can use directly over MCP, so people and assistants work from the same list.
- [**applenotes**](https://github.com/gig3m/applenotes): read and write Apple Notes from anywhere over REST and MCP, with an old Mac as the bridge. [**anotes**](https://github.com/gig3m/anotes) is the desktop app on top.
- [**drip**](https://github.com/gig3m/drip): push a screenshot or file to your own server and hand a coding agent an expiring link.
- [**claude-api-usage**](https://github.com/gig3m/claude-api-usage): see AI API spend against a monthly budget at a glance.
